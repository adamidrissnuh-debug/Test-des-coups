# GoReactive · collecte de mouvements

Page web (Android + iPhone, sans installation) qui enregistre les points du squelette (épaules, coudes, poignets) pendant
des coups de boxe, pour améliorer la détection de l'app GoReactive. **Aucune image ni vidéo n'est enregistrée.**

Page générée depuis le dépôt de l'app (`npm run collecte:build`) : ne pas modifier ici.
Détection : MediaPipe Pose (Google, Apache 2.0, voir `LICENCE-MediaPipe-Apache-2.0.txt`).
